# NeoVerse Product Launch Storyboard

## Runtime

Target runtime: approximately 52 seconds. Timing is a guide; the edit should breathe around real product interactions.

## Edit grammar

- Start with an object, not a logo.
- Use one dominant visual object per shot.
- Let rules, alignment, and measured transitions create motion.
- Use electric blue only for an active interaction or focus state.
- Use lime only for a real confirmation or availability state.
- Keep cuts intentional and relatively slow; the product should be understood before the next beat.

## Transition language

- Editorial wipes following panel edges.
- Evidence rows aligning into place.
- Product-image crops becoming interface surfaces.
- A cursor/gesture-driven handoff into 3D.
- A restrained fade to the end card.

Avoid glitch transitions, lens flares, particle dissolves, camera shake, and generic zoom-through-device effects.

## Capture checklist

- Home/evidence stage at desktop resolution.
- Product detail page with a supported product and real product facts.
- Catalog search/filter or comparison state.
- 3D viewer with an explicit interaction.
- AR/spatial state where supported; otherwise use the honest unsupported/device-state surface.
- Cart or checkout summary with real visible state.
- Final logo mark and wordmark from the repository.

## Claims checklist

Before final render, verify every visible claim against the current implementation:

- Product name and image correspond.
- Dimensions and material are real data.
- Price and inventory state are not presented as invented.
- AR/3D labels reflect actual product/device capability.
- Checkout wording does not imply that catalog/API identity unification is complete.
- No unverified performance, adoption, or business metrics appear.
